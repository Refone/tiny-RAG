# CSR, Compressed Sparse Row 压缩稀疏行

## 一、CSR 是什么

CSR（Compressed Sparse Row，压缩稀疏行）是一种专门存储稀疏矩阵的格式。它只记录非零元素，从而避免为大量 0 浪费内存。CSR 用三个一维数组表示一个 $n \times m$ 的稀疏矩阵：

| 数组      | 含义                                                 | 长度    |
| --------- | ---------------------------------------------------- | ------- |
| `data`    | 所有非零元素的值，按行优先顺序排列                   | `nnz`   |
| `indices` | 每个非零元素对应的列索引                             | `nnz`   |
| `indptr`  | 每一行第一个非零元素在 `data`/`indices` 中的起始位置 | `n + 1` |

第 `i` 行的非零元素范围是：

```python
data[indptr[i] : indptr[i+1]]
indices[indptr[i] : indptr[i+1]]
```

举例，一个 $3 \times 5$ 的矩阵：

```
[[0, 0, 3, 0, 4],
 [0, 0, 0, 0, 0],
 [1, 0, 0, 0, 2]]
```

CSR 表示为：

```python
data    = [3, 4, 1, 2]
indices = [2, 4, 0, 4]
indptr  = [0, 2, 2, 4]   # 长度 n+1
```

- 第 0 行：`data[0:2] = [3,4]`，列索引 `[2,4]`
- 第 1 行：`data[2:2] = []`，空行
- 第 2 行：`data[2:4] = [1,2]`，列索引 `[0,4]`

**优点**：按行切片极快、内存紧凑、适合行向量检索。
**缺点**：按列切片慢、动态修改成本高。
